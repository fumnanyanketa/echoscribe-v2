# AC-6: two Ctrl presses with another key in between do not start dictation

Live run, 2026-08-29.

## Outcome: met

## What was observed

Step 4. Pill closed. The user clicked into a text field, typed a word,
then pressed Ctrl+C followed by Ctrl+V.

User: "Ctrl+C followed by Ctrl+V does not make the pill appear."

No pill, so no dictation started. This is the everyday case the criterion
exists for, and it holds.

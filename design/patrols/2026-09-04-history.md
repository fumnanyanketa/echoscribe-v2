# Drift patrol, 2026-09-04, plan row 5

Scope: the one surface record 0007 is about to build, History, plus the two
rows in the shell that its arrival changes, `Nav rail` and
`Settings, could not be read`. **Nothing is built yet.** This is the pass the
registry's own header demands before a build, "a component not on this list does
not exist", and it ran in the same session as record 0007 because the user was
away and asked for plan row 5 end to end.

This is the third patrol written to a file, after
[2026-09-04.md](2026-09-04.md) for the Settings, Dictation surface and
[2026-09-04-rows-3-and-4.md](2026-09-04-rows-3-and-4.md) for Vocabulary and
Languages, both earlier the same day.

**Two things make this patrol different from the two before it.** History is the
one section of this app that was drawn first and built last: seven rows have sat
on this list since the day it was written, describing a screen nobody had
designed. So this is the first patrol where the majority of the findings are
**rows that were already here and were wrong**, which is the more dangerous
kind: a missing row stops a build, and a wrong row gets followed. And one
finding is not a design finding at all. `Copy action` is refused by AGENTS.md's
data rules, not by this list's taste, and it is recorded here as refused rather
than retired so that nobody reads it as a drawing decision that could be undone
by drawing it differently.

## What was clean

- **No new token, anywhere.** Every one of the new and corrected rows is built
  from tokens that exist: `--color-surface-subtle` at `--radius-md` for a row,
  which `Term row` established; `--color-surface-subtle` at `--radius-lg` with
  `--color-border-control` for the field, and see the finding above for why it
  is not `sunken`; `--color-ink` for a transcript, `--color-ink-caption` for its
  metadata line, `--color-ink-secondary` for the count and the paragraph;
  `Mono badge` for the language tag; `Secondary button` and
  `Text button and link` for the two actions.
- **No new contrast pair.** `python design/check-contrast.py` was run and all 59
  pass, unchanged, and every pair the new rows use is already audited under
  another name, which each row says: the transcript as "Keycap text on a row",
  its metadata as "Caption on a row", the language tag as "Hotkey CHOSEN badge",
  the field's edge as "Control edge on a row", the count and the paragraph as
  "Secondary body", the empty state's first line as "Heading and body". Nothing
  was added to that file, and that is the right outcome rather than a skipped
  step.
- **Reuse beat reinvention five times**, which is the rule least visible in a
  diff. The search field is `Language filter`'s primitive. The older action is
  `Secondary button`. The read failure is `Settings, could not be read`
  widened, not copied. The row fill is `Term row`'s. The empty state's keys are
  `Hotkey choice`'s keycap treatment, so one hotkey looks like one thing
  wherever it appears.
- **Nothing on the "not in the registry, on purpose" list crept in.** No modal
  and no confirmation, because there is nothing on this screen to confirm. No
  toast when a search returns. No tooltip on the language tag, which was the
  tempting way to explain `zh-TW` and is refused: a tag is quoted, and the row
  that needs explaining is `Multilingual row`, which has a second line instead.
  No icon button without a label, which is the usual shape a Copy action takes
  and a second reason that row is not being built quietly.
- **The two-signal rule holds in every new state.** A search matching nothing is
  a sentence and an empty list. A history that cannot be read is a code and a
  sentence. An empty history is a line and a paragraph. Nothing rests on colour,
  and there is no colour on this surface carrying meaning at all except the
  error line's, which has words beside it.
- **The empty state exception registered on 2026-09-04 for Vocabulary still
  reads correctly.** That row deviates from the empty state rule and says so;
  this one follows it in full, which is what makes the deviation legible rather
  than a precedent.

## Registry

**Two added, seven corrected in place, one refused, one duplication avoided.**

Added: `Older dictations action` and `History, could not be read`. The second is
registered as explicitly **not** a component of its own, for the reason
`Vocabulary, could not be read` gives and one History adds: a search field over
a list that could not be read invites a person to search a history the app
cannot see, and the empty result would be indistinguishable from an empty
history.

Corrected in place: `Search field`, `Result count`, `Dictation row`,
`Language tag`, `History empty state`, `Nav rail`, and
`Settings, could not be read`.

Retired with the reasoning kept: `Filter chip`.

Refused, which is a different thing and is recorded as one: `Copy action`.

The duplication avoided is a "History, no matches" row of its own. It is folded
into `Search field`, exactly as `Language filter` folds its own, because a state
belongs to the control that causes it.

## System changes

**None proposed.** No token was invented, no pair went unaudited, and
`design/design-system.md` is untouched.

One thing about the law is worth repeating rather than changing, because this
patrol is the reason it exists. The empty state rule reads as though it applies
to every empty state in the app, and it was written for this one. History now
follows it in full and Vocabulary is a registered deviation with its reason. Two
surfaces, one rule, one exception: that is a healthy shape. A third exception
would mean the rule is wrong, and that is a conversation rather than a patrol.

## Routed to /develop

Nothing to fix, because nothing is built. What is handed over is the rows above
as the spec, plus five things a build must not do, each of which this patrol
expects to be tempting:

1. **Do not reach for `--color-surface-sunken` for the search field**, however
   exactly its comment fits. Its control edge is 2.87:1 and the mandate needs
   3:1. This is the second patrol running to say so.
2. **Do not put a Copy button on a row**, and do not reach for
   `navigator.clipboard` from anywhere on this screen. It is refused by a data
   rule until the user says otherwise.
3. **Do not truncate a transcript, or clamp it to a few lines with a fade.** It
   will look better and it hides the one thing this screen exists to show.
4. **Do not set any part of a dictation as HTML.** Every string is
   `textContent`, and record 0007 asks for a Rust source guard that fails the
   build if `innerHTML` and its neighbours appear in `src/history/history.js`.
   That is the one finding on this surface that is a security control rather
   than a look.
5. **Do not hold a list of right to left languages.** `dir="auto"` is the whole
   mechanism, here as on the pill.

inconsistency.
